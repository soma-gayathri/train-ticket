# Station suggestions

The directory includes popular railway destinations across India, alongside the
stations used by the illustrative schedules. It is a curated directory, not a
claim to list every Indian railway station. Adding a station does not add any
train schedules for it.

Additional station codes were checked against Indian Railways' station list:
https://indianrailways.gov.in/railwayboard/uploads/directorate/traffic_comm/Station_Name_8477.pdf
(accessed 20 October 2026). Display names use familiar spellings; HX is shown as
Kadapa (listed as Cuddapah). Common city names and older spellings are supported
by `public/station-autocomplete.js`.

Additional major-city station references:
https://www.indianrail.gov.in/availability_Trains_From_Major_Cities.html
https://sr.indianrailways.gov.in/cris/uploads/files/1704884753376-De-reserved%20SL_coach%2010-JAN-2024.pdf
https://sr.indianrailways.gov.in/cris/uploads/files/1748431911655-System%20Map%202025%20Signed.pdf

Both station inputs match name prefixes, significant words, common city names,
and station-code prefixes. All matches appear in a scrollable dropdown. Arrow
keys move through results; Enter selects; Escape and Tab dismiss the list.
